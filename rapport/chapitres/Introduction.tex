\section{Introduction}

Ce laboratoire porte sur l'identification expérimentale des paramètres d'un actionneur électrodynamique à bobine mobile, du type utilisé pour le positionnement des têtes de lecture des disques durs (\emph{Voice Coil Motor}, VCM). Ce transducteur à déflexion angulaire limitée se rencontre aussi dans les galvanomètres, les têtes d'impression et les scanners laser.

Le système est entièrement caractérisé par six paramètres physiques :
\begin{itemize}
    \item \(R\) : résistance de la bobine [\si{\ohm}] ;
    \item \(L\) : inductance de la bobine [\si{H}] ;
    \item \(K_u = K_t\) : constante électromécanique de couplage [\si{V.s/rad} = \si{N.m/A}] ;
    \item \(J\) : moment d'inertie de la partie mobile [\si{kg.m^2}] ;
    \item \(C_v\) : coefficient d'amortissement visqueux [\si{N.m.s/rad}] ;
    \item \(K_r\) : raideur du rappel élastique [\si{N.m/rad}].
\end{itemize}

Trois expériences complémentaires sont menées pour identifier ces six paramètres :
\begin{itemize}
    \item \textbf{EX1} -- réponse indicielle, bobine bloquée et libre : identification de \(R\) et \(L\) ;
    \item \textbf{EX2} -- oscillations libres, bobine ouverte : identification de \(\delta = C_v/(2J)\), \(\omega_n^2 = K_r/J\) et \(K_u\) ;
    \item \textbf{EX3} -- oscillations libres, bobine court-circuitée : extraction de \(J\), \(C_v\) et \(K_r\) par comparaison avec EX2.
\end{itemize}

Les acquisitions sont réalisées à l'oscilloscope Tektronix DPO2014B. Chaque essai contient \(125\,000\) points par voie, avec une base de temps adaptée afin de couvrir soit la dynamique électrique rapide, soit la dynamique mécanique lente. Les mesures sont post-traitées en Python : détection des fronts, fit exponentiel, détection des extrema oscillants, calcul des paramètres et superpositions mesure/modèle.

\paragraph{Données de l'actionneur.}
L'angle de déflexion maximal est \(\Delta\alpha_{\max} = \SI{17{,}1}{\degree} = \SI{0{,}2985}{rad}\). Pour le calcul du nombre de spires, l'induction dans l'entrefer est \(B = \SI{0{,}45}{T}\), avec un rayon extérieur de la bobine de \(\SI{30}{mm}\) et un rayon intérieur de \(\SI{15}{mm}\). Le courant doit rester inférieur à \(\SI{0{,}2}{A}\) pour des raisons thermiques.
